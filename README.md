# nmap-labs
Personal notes and hands-on labs for learning network scanning with Nmap

This repository contains notes and small labs I made while learning
how network scanning works using Nmap.

I created this repo mainly to keep track of what I learn and to better
understand the basics of network enumeration before going deeper
into cybersecurity topics.

---

## What is inside
- basic Nmap scans
- simple examples of open ports and services
- short explanations based on my own understanding

---

## Tools
- Nmap
- Kali Linux
- VirtualMachine (VMWare Workstation Pro)

---

## Current level
Beginner (still learning and practicing)
